# Art requests

Anyone adds a row; Art owns the status. Formats: `docs/asset-spec.md`. Every unit names its strike
type (pose standard): chop, double, sweep, upward, thrust, smash, bolt or shot.

| Order | Request                                                                                                           | Ids                             | Status |
| ----- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------- | ------ |
| 10    | Heroes tier 1: Warrior (chop), Ranger (shot), Wizard (bolt), Paladin (smash), Rogue (double)                      | `hero_<class>_t1_<front\|back>` | Open   |
| 20    | Monsters tier 1: draugr (chop), troll (smash), harpy (upward), minotaur (chop), jackal-man (sweep), wyrm (thrust) | `mon_<type>_t1_<front\|back>`   | Open   |
| 30    | Buildings tier 1: town hall, temple x3 (Aesir, Greek, Egyptian), market, smithy, shrine, guard tower              | `bld_<type>_t1`                 | Open   |
