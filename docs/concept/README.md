# Concept art (Stefan)

Stefan's own earlier concept sheets, the direction reference for all art. Heroes: detailed
hi-bit pixel art, dark palette (black, navy, bronze-gold), each Godblood shown across tiers that
grow from a plain recruit to a radiant demigod. Monsters: grim painted bestiaries per pantheon
(Aesir, Greek, Egyptian), useful for monster designs and the bestiary list.

Stefan's notes: grittier than the S1 picks, and it must work with simple animations.
