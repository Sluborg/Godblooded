# S4: chunky test, five units (5 images)

Track: heroes (this test batch also holds two monsters). **Priority: make this before anything
else.** Each item is **one still picture**; the game does all motion in code (hop, lunge,
flash), so no frames.

**Chunky (all five):** about **3 to 3.5 heads tall**, a big head with a readable face, big
hands and feet, an **oversized weapon** (and shield where the unit has one), a wide planted
stance, a **thick dark outline**. Grim, not cute: keep the gritty palette (black, navy,
bronze-gold, worn leather, scars) and every detail that makes the unit itself. Detailed pixel-art
rendering like Stefan's concept sheets (`docs/concept/`). **This batch overrides the proportions
in `STYLE.md`** (which still says 4.5 heads); everything else in `STYLE.md` still applies.

**Framing (all five):** whole body, turned slightly toward the lower **right** (every picture
faces right), weapon clearly visible and not cropped, feet at about 88% of the canvas height,
figure about 75% of the canvas height (the troll fills more, see item 5). **Flat magenta #FF00FF
background**, no ground, no shadow, nothing else in the picture.
