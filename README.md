# Godblooded

A Majesty-inspired kingdom builder with roguelite runs. You build the town; Godbloods, the
mortal-born children of the old gods, form parties and go monster hunting on their own. You steer
them only with buildings, bounties and the upgrades you pick when a party levels up.

**Play:** https://sluborg.github.io/Godblooded/ (landscape, installable: Chrome, "Add to Home
screen")

## Develop

```bash
npm install
npm run dev      # dev server on the LAN
npm test         # simulation unit tests (vitest)
npm run build    # typecheck + production build
npm run lint
npm run format
```

Every push to `main` deploys to GitHub Pages. Conventions: [CLAUDE.md](CLAUDE.md).
